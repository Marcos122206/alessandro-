# Alessandro Rodrigues — Consultoria e Treinamentos

Site estático pronto para Vercel. Abra `index.html` ou rode `python3 -m http.server 8000`.

## Versões

A versão anterior ao novo layout está preservada no ZIP da pasta irmã `../cursos-backups/`. Para restaurar, extraia esse ZIP na pasta do projeto. O backup não faz parte do site publicado.

## Publicação

Envie `index.html`, `styles.css`, `script.js`, `vercel.json` e a pasta `assets` ao repositório conectado à Vercel. Framework: Other; sem comando de build; saída: `.`.

## Contato e conteúdo

O formulário abre o WhatsApp com os dados preenchidos; não envia e-mail nem armazena dados no servidor. Número de destino preservado da versão anterior: 5535997260815. O catálogo de cursos e seu seletor foram removidos a pedido do titular. O banner tem navegação manual para evitar movimentação automática.

A redação dos registros profissionais e credenciamento dos certificados aguarda esclarecimento do titular.
